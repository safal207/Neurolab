# Neurolab: воспроизводимый эксперимент в Colab

Откройте [ноутбук](https://colab.research.google.com/github/safal207/Neurolab/blob/codex/neurolab-colab-lab/notebooks/neurolab_emobank_lab.ipynb), при желании сохраните копию в Drive и выберите Runtime → Run all. Достаточно CPU. Установка и загрузка данных требуют интернета.

Ноутбук устанавливает зависимости, получает закреплённую версию кода и EmoBank, обучает две версии Neurolab и сравнивает их с простыми методами. Параметры видны в отдельной ячейке. Нажмите Run all повторно для нового полного эксперимента; результат сохраняется в отдельном каталоге.

V — положительность текста, A — возбуждение, D — ощущение контроля в аннотациях. Таблицы показывают оценки на шкале 1–5 и среднюю абсолютную ошибку; меньшая ошибка лучше. Это оценки текстовых аннотаций, а не диагностика человека.

Обучение использует 3 000 случайно выбранных строк официального train, seed 42 и 10 эпох. Данные dev выбирают регуляризацию Ridge и эпоху сохранения нейросети. Test используется для итоговых чисел. Из dev/test удаляются точные совпадения текста с предыдущими выборками; ноутбук показывает число исключений.

Графики отвечают на три вопроса: какова ошибка на test, как менялась ошибка на dev, насколько отличие от Ridge устойчиво к пересэмплированию тестовых строк. Интервал пересэмплирования относится к одному обучению и не заменяет прогоны с несколькими seed.

В ячейке с TEXTS можно ввести свои английские предложения. Демо повторно загружает сохранённые веса и обработку текста. Поддержку русского языка этот эксперимент не проверяет.

В конце скачивается ZIP с весами, обработкой текста, таблицами, численными прогнозами, графиками и сведениями об источнике. Сохраните его: временное окружение Colab может завершиться. Для локального повторения используйте команды из README.

Первый быстрый эксперимент не показал превосходства над Ridge. Следующий шаг — заранее зафиксировать новую проверку: несколько seed, более сильные текстовые признаки и отдельно обучение/оценка механизма памяти на последовательностях.
