# Как использовать Neurolab как актив

Первый актив — открытый, воспроизводимый исследовательский кейс: читатель запускает Colab, получает обученную модель, видит базовые сравнения и может проверить численные результаты. Он полезен в портфолио QA/AI-инженера, на занятии по проверке ML и в разговоре о качестве агентных продуктов.

Главный демонстрационный вопрос: «Дополнительная сложность модели действительно улучшает результат на новых текстах?» История проекта показывает и исправление утечки правильных ответов, и проверку сохранённых весов, и результат, где простой метод остался сильнее по точечной оценке.

Предлагаемый платный формат — согласованный эксперимент на данных клиента: определить задачу и разметку, сравнить базовый метод с одним усложнением, разобрать ошибки и подготовить воспроизводимый отчёт. Объём, доступ к данным, метрики и цена согласуются под конкретный пилот. Продажи и спрос этим выпуском ещё не подтверждены.

Для первого знакомства достаточно ссылки на Colab, графика сравнения и короткого объяснения результата. Успешный следующий этап: несколько независимых пользователей прошли запуск и хотя бы один принёс собственную задачу для сравнения.

Исследовательская дорожка: повторить несколько seed; проверить более сильные фиксированные признаки; сравнить K=1/5 при согласованном бюджете вычислений; исследовать память на действительно упорядоченных последовательностях. Каждая новая проверка получает отдельный протокол и отчёт. Текущий результат не переносится автоматически на новые данные, признаки, языки или клинические задачи.
