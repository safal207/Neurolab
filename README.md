# Neurolab · LIMINAL Heartbeat

A reproducible research lab for recursive prediction of text emotion ratings.

**Question:** does repeated refinement improve Valence, Arousal and Dominance prediction over a simple linear baseline?

The maintained lab trains a model, selects its checkpoint on development data, evaluates held-out text, and saves everything needed to repeat inference. The original research notebook and model family remain available.

[Open the Colab lab](https://colab.research.google.com/github/safal207/Neurolab/blob/codex/neurolab-colab-lab/notebooks/neurolab_emobank_lab.ipynb) · [Russian walkthrough](docs/COLAB_LAB_RU.md) · [Recorded experiment](evidence/EMOBANK_QUICK_RUN.md)

## What you can run

| Route | Result |
| --- | --- |
| Colab: Runtime → Run all | Trained weights, baseline comparison, three figures, reload check and downloadable bundle |
| Local experiment | The same CPU workflow with explicit parameters |
| Trained demo | V/A/D estimates from saved weights and saved text preprocessing |
| Original Osozn3.ipynb | Historical exploratory notebook, outside the maintained lab validation |

No GPU, paid API, or downloaded language-model weights are required. The lightweight lab uses train-fitted TF-IDF → SVD → scaling to test the recursive model, rather than claiming to reproduce a transformer-backed experiment.

## Local quickstart

Python 3.11 or later:

~~~bash
python -m pip install -r requirements-lab.txt
python -m neurolab.experiment --output-dir artifacts/neurolab-lab
python demo.py --bundle artifacts/neurolab-lab --text "I am happy about this result."
python -m unittest discover -s tests -v
~~~

Default experiment: seed 42, 3,000 training rows, 64 features, 10 epochs, K=1 and K=5. Use --max-train 0 for all official training rows. Changing the experiment creates new evidence; results from different configurations should be kept separate.

## Evaluation contract

- Source: pinned [EmoBank](https://github.com/JULIELab/EmoBank) bytes and its official train/dev/test assignments.
- Exact text overlap is excluded from held-out subsets; counts and ID hashes are reported.
- Vocabulary, dimensionality reduction and scaling fit training text only.
- Labels are transformed from 1–5 to −1…1 for training; MAE is reported back in **original 1–5 points**. Lower is better.
- Targets enter the loss, never the model's affect input.
- Independent-text inference has persistent memory disabled. Experimental stream memory is explicit, singleton-only, and resettable.
- Ridge regularization, neural epochs and the inference checkpoint are selected on **dev only**. Test labels do not select them.
- Mean, Ridge, K=1 and K=5 use the same rows. Paired row-bootstrap intervals compare neural error to Ridge at this one trained seed; they do not cover variability across training seeds.

## Current evidence

The first bounded quick run used 3,000 train / 985 dev / 984 test rows after overlap exclusions. Test mean MAE was **0.1944 for Ridge**, **0.1988 for K=1**, and **0.1951 for K=5**. Five-pass inference improved the point estimate over one-pass inference, while superiority over Ridge was not established. See the recorded report for precise scope, environments, intervals and provenance.

These are English text annotation estimates from one lexical-feature configuration. They do not establish a person's emotional state, calibrated confidence, clinical utility, consciousness or a general architecture advantage. The repository's Hope/Faith/Love names are experimental metaphors, not independently validated psychological measurements.

## Saved bundle

- features.joblib: fitted vocabulary, SVD and scaling;
- model_k1.pt / model_k5.pt: trained states and inference settings;
- ridge.joblib: fitted baseline;
- report.json / metrics.csv / training.csv: results, selection and provenance;
- test_predictions.npz: numeric predictions for independent metric checks;
- ATTRIBUTION.txt: dataset attribution.

Use bundles generated by a trusted local run; joblib stores Python objects. The demo requires a trained bundle and no longer presents a random initial model as a working emotion recognizer.
